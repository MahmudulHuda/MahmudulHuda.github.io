About Me

Welcome to my site!

My name is Syed Mahmudul Huda, and I am the most positive person I have ever seen. This positivity is the sole reason for my energetic personality and strong relations with my peers and co-workers. My biggest fear is time, which is why I set deadlines for every task I take on, using that fear to stay punctual.

Research & Development Projects

Alzheimer’s & Dementia Care Assistant Code

Python, scikit-learn, Flask, Hugging Face Transformers

  • System: Built a Q&A assistant in English, Bangla and Chinese that helps dementia caregivers find trusted NIH health information, using 107 question–answer pairs curated from the MedQuAD dataset.
  • Retrieval: Designed a lightweight character n-gram TF-IDF search that works across all three languages on a CPU, with no language-specific tokenisers.
  • Safety: Added a confidence threshold so the assistant says “not sure” instead of guessing, and a three-language emergency check that flags urgent messages (e.g., a missing person).
  • Engineering: Translated the knowledge base offline with Meta’s NLLB-200; shipped as a Flask web app and terminal tool with 25 automated tests on GitHub Actions; open source (MIT).

Maternal Health Risk Classification Code

Python, scikit-learn, pandas

  • Pipeline: Built an ML pipeline to classify pregnancy risk (low / mid / high) from six clinical readings, using the UCI Maternal Health Risk dataset (1,014 records from rural Bangladesh).
  • Data Audit: Found 55% duplicate records and conflicting labels that inflated macro F1 to 0.85; cleaned to 380 reliable records and switched to grouped cross-validation.
  • Result: Compared Random Forest, Gradient Boosting and Logistic Regression against a baseline; the best model reached macro F1 of 0.67 and 72% accuracy on a held-out test set.

Tweet Sentiment Analysis: COVID-19 Vaccine Code

Python, scikit-learn, TextBlob, VADER

  • Data: Cleaned about 11,000 public tweets on the Pfizer/BioNTech vaccine (Kaggle) and labelled them positive, neutral or negative with TextBlob.
  • Model: Trained a TF-IDF + Logistic Regression classifier reaching 84.49% test accuracy on the TextBlob labels; measured how often TextBlob and VADER agree.
  • Analysis: Produced 7 charts: sentiment spread, weekly trends, top words per class, confusion matrix.
